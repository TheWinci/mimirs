# Optional test probes

These modules are unchanged copies of the test-only probes originally kept
under `benchmarks/versions/`. They are included by the storage and embedding
unit-test modules. Optional runs still require their documented environment
variables and disposable input data. Moving the modules does not enable those
runs in the default suite. No run data or model assets are included.
